TRANSPARENT URL CHECKS

Analysis Method

This application uses deterministic URL heuristics, not a trained machine-learning model.

Local analysis

Signals evaluated

The scanner checks the URL protocol, embedded credentials, IP-address hosts, URL length, subdomain depth, hostname hyphens, and potentially deceptive URL terms.

0–29Safe
30–59Phishing
